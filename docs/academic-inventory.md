# Academic inventory mode

This mode is for the local school project. It does not represent real property offers, ownership verification, live availability, signed investments, or approved production FX rates. The site-wide academic notice has been removed from the public layout. Property descriptions still identify illustrative locations, prices, availability, and imagery. Record provenance remains internal (`isDemo`, `academicVisible`, and `sourceProvider=globalhome-academic-v1`). Real inventory continues to require the existing verification and publication workflow.

The mode is enabled only when `NODE_ENV` is not `production`, `MONGODB_DB_NAME=globalhome_dev`, and `ACADEMIC_INVENTORY_ENABLED=true`. Production builds and other databases use the real verified-property filter. Do not deploy the development server as a production service.

If `/en/properties` shows zero despite a populated `globalhome_dev`, confirm the ignored local environment file has both `MONGODB_DB_NAME=globalhome_dev` and `ACADEMIC_INVENTORY_ENABLED=true`, then restart `npm run dev`. The publication filter is selected when the server starts. The default catalogue should show the academic records. The visible catalogue form contains only Search, Country, and Search; production verification rules remain enforced internally. Run `npm run inventory:academic:audit` to check the database count without generating records.

Before population, create the first verified development administrator with the existing bootstrap command and privately configured credentials. Then run:

```powershell
npm run inventory:academic:populate -- --populate
npm run inventory:academic:audit
npm run dev
```

The generator reads enabled countries from MongoDB, defaults to 100 records each, and uses deterministic IDs with insert-only bulk upserts. It never deletes or updates externally sourced properties. `--count=500` raises the minimum to 500 per enabled country. It stops before writing if an enabled country lacks academic location or currency reference data.

The October 2026 academic revision updates the existing deterministic records in place. Run `npm run inventory:academic:update` for a read-only identity/count preview, then `npm run inventory:academic:update -- --update` only against `globalhome_dev`. The update refuses a count other than 24,300 or an image library below 1,000 assets, verifies all expected IDs and unique title/location combinations before writing, uses no upserts or deletes, and matches the academic source on every update. `npm run inventory:academic:corrections-audit` checks every record's country count, identity, price, 30% projected rate, and image assignment. `npm run inventory:academic:images:audit` checks local image files, galleries, within-country cover uniqueness, and cross-country cover reuse. Current reference ranges are USD $2,000–$20,000 rent monthly; $5,000–$70,000 lease monthly; $2,000–$200,000 investment; and $20,000–$900,000 purchase. Real admin-created prices are not silently rewritten.

`src/data/academic-locations.json` contains a reviewed primary city position for all 243 enabled countries. They are approximate map positions, not property coordinates. The data was derived from [mledoze/countries](https://github.com/mledoze/countries) and the [country-capitals table](https://github.com/katerinaSo/countries_cities_data/blob/main/country-capitals.csv); the small number of uncovered territories have reviewed fallback positions. Hong Kong and Macao positions use their respective [Lands Department](https://www.landsd.gov.hk/en/resources/mapping-information/hk-geographic-data.html) and [Government Tourism Office](https://www.macaotourism.gov.mo/en/article/about-macao/location-and-time) geographic descriptions. `src/data/academic-cities.json` adds city and region variation from the [GeoNames free data export](https://download.geonames.org/export/dump/) under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Coordinates are city centroids, never verified property coordinates. The generator uses up to five additional real city centroids where available. GeoNames is credited here for the derived city data.

To regenerate the derived city file, download `cities15000.zip` and `admin1CodesASCII.txt` from GeoNames, extract `cities15000.txt` into `tmp-academic-cities/`, then run `node scripts/buildAcademicCities.mjs`. The downloaded source files need not remain in the repository.

`src/data/academic-fx.json` contains a fixed 2026-10-28 [ExchangeRate-API open snapshot](https://open.er-api.com/v6/latest/USD) for academic pricing. KPW uses the 2026-10-27 official-rate estimate from [WorldData](https://www.worlddata.info/currencies/kpw-north-korean-won.php), whose page cautions that the official rate does not reflect local market exchange. Neither snapshot is inserted as an approved `FxRate` record.

The original 12 illustrative images under `public/images/academic/` were generated for this project. The expanded local library under `public/images/academic/library/` consists of selected [Wikimedia Commons](https://commons.wikimedia.org/wiki/Commons:Reusing_content_outside_Wikimedia) images. Each source file's author, page, and license are stored in `src/data/academic-images.json`; public cards display author and license, and detail pages link to source and license. Files were resized and converted to WebP for display. They are illustrative and are not photographs of the listed academic addresses. Commons licensing varies by file, so review individual metadata before use outside this school project. The source scripts only write image files and metadata; they do not change MongoDB. Image assignments are deterministic, distinct across each country's 100 covers, and prioritize available country-specific house images. A library of 1,000 images cannot give all 24,300 records globally unique cover photos; that would require at least 24,300 genuinely distinct images.

The optional `npm run inventory:academic:images:source` and `npm run inventory:academic:images:country-source` commands append new licensed Commons files to the local attribution manifest. They do not update listings. Review any newly sourced files, run `npm run inventory:academic:update` for a read-only preview, and use the guarded `-- --update` form only for authorized academic records. `node scripts/pruneUntrackedAcademicImages.mjs` previews untracked library files; `--prune` removes only files absent from the attribution manifest.
